# yashbaruah.com

Personal website for Yash Baruah — CS senior at UT Dallas.

Built with React (Create React App) and a hand-rolled design system: Inter / Space Grotesk / JetBrains Mono, a single indigo accent, and light + dark themes.

## Develop

```
npm install
npm start
```

## Deploy

```
npm run deploy
```

Builds the site (including a `404.html` SPA fallback and the `CNAME` file) and pushes it to the `gh-pages` branch, which GitHub Pages serves at [yashbaruah.com](https://yashbaruah.com).
